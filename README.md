# Portafolio de captura y validación en Excel

Proyecto demostrativo desarrollado por **Ángel Gabriel Valderrama Ramírez** para presentar habilidades de captura de datos, validación documental, control de calidad y seguimiento operativo en Excel.

El libro simula una operación de *back office* bancario mediante información completamente ficticia. Su propósito es demostrar competencias aplicables a puestos de **Capturista**, **Auxiliar Administrativo**, **Data Entry** y **Back Office**.

## Habilidades demostradas

- Captura estructurada y organización de registros.
- Uso de tablas, filtros y catálogos de datos.
- Fórmulas para validación y control operativo.
- Detección automática de folios duplicados.
- Revisión de integridad y estatus documental.
- Comparación de tiempos contra objetivos de servicio (SLA).
- Listas desplegables para prevenir errores de captura.

- Creación de indicadores y gráficos conectados a los datos.

## Controles automatizados

El archivo calcula y muestra automáticamente:

1. **Duplicidad:** identifica folios repetidos y los marca para revisión.
2. **Integridad:** comprueba que los campos obligatorios estén completos.
3. **Control documental:** valida el estatus de los documentos capturados.
4. **Cumplimiento de SLA:** compara el tiempo de atención con el objetivo de cada trámite.
5. **Resultado:** clasifica cada registro como `APROBADO` o `REVISAR` de acuerdo con los controles anteriores.

Las reglas se encuentran visibles dentro del libro para facilitar su revisión y auditoría. No se utilizan macros ocultas.

## Cómo probar el proyecto

1. Descarga y abre el archivo en Microsoft Excel.
2. Ingresa a la hoja `Captura`.
3. Copia un folio existente en otro registro para comprobar la detección de duplicados.
4. Vacía un campo obligatorio para observar el cambio en el control de integridad.
5. Cambia el estatus de un documento a `No legible` o `Incompleto`.
6. Incrementa los minutos de atención por encima del SLA correspondiente.
7. Regresa al `Dashboard` para verificar la actualización de los indicadores.
